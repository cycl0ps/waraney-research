# PEX02 – Transformer-Based Detector Development

## Overview

PEX02 merupakan eksperimen kedua dalam rangkaian Preliminary Experiments yang berfokus pada pengembangan model deteksi AI-generated text menggunakan pendekatan Transformer-based Language Models.

Eksperimen ini bertujuan untuk membangun, mengevaluasi, dan membandingkan berbagai konfigurasi model guna mengidentifikasi pendekatan yang efektif untuk membedakan teks yang ditulis manusia dan teks yang dihasilkan oleh AI.

## Objectives

- Mengembangkan baseline detector berbasis Transformer.
- Mengevaluasi performa berbagai konfigurasi model.
- Menganalisis pengaruh dataset, preprocessing, dan feature engineering terhadap performa deteksi.
- Menghasilkan kandidat model untuk publikasi dan eksperimen lanjutan.

## Expected Outputs

- WARANEY-0.1.0
- WARANEY-0.2.0
- WARANEY-0.3.0
