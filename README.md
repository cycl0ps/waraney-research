# WARANEY Research

Research repository for WARANEY, an AI-generated text detection project.

## Objectives

- Benchmark existing detectors (PEX01)
- Develop WARANEY v0 baseline detector (PEX02)
- Evolve WARANEY into a robust and explainable AI text detection framework

## Repository Structure

- `docs/` : project documentation
- `configs/` : experiment configurations
- `experiments/` : experiment records
- `notebooks/` : Colab notebooks
- `src/` : reusable source code
- `scripts/` : utility scripts
- `tests/` : tests

## Current Stage

- PEX01: Benchmarking existing detectors
- PEX02: WARANEY v0 development
